# Painel de Diagnóstico Financeiro (Regra 50-30-20)

Aplicação web interativa para planejamento orçamentário mensal e diagnóstico patrimonial baseada na Regra 50-30-20.

## Funcionalidades
- Controle e persistência mensal via `LocalStorage`.
- Categorização de despesas: Essenciais (50%), Desejos Pessoais (30%) e Prioridades/Investimentos (20%).
- Detecção automática de vazamentos orçamentários e maior despesa individual.
- Metas de independência financeira e reserva de emergência.
- Emissão de parecer financeiro automatizado com recomendações práticas.

## Tecnologias
- HTML5, CSS3 moderno (Design responsivo Dark Mode)
- JavaScript Vanilla
- Chart.js via CDN
